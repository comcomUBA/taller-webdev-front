# Taller de WebDev

Este es el contenido del taller de desarrollo web de la ComCom.

Las diapos están en `diapos/` (inesperado). Hay una versión web y otra 
hecha en LaTeX. Recomendamos la versión web ya que es más completa y 
tiene menos errores. La versión web empieza en `diapos/web/introduccion.html`
y la versión en LaTeX está en `diapos/latex/src/clase.pdf`.

Los ejercicios a resolver están en `ejercicios` y se pueden encontrar 
resoluciones para los mismos en `resueltos`. Se puede llegar a ambos lugares 
desde `index.html`.

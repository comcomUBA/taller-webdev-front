Hypertext Markup Language (HTML)

HTML es un lenguaje para armar documentos. "Hypertext" se refiere a los links que conectan los distintos sitios y documentos. "Markup" se refiere a que se usa una sintaxis particular para marcar cómo se debería estructurar el contenido.
La sintaxis de HTML consiste en el uso de tags. Hay alrededor de 140 de estas tags, pero lo normal es usar un subconjunto bastante más chico de ellas.
Las tags tienen el formato <tag atributos>Contenido</tag> o <tag atributos/> para elementos sin contenido. Dicho contenido podría ser texto o incluso otras tags. Veamos cuáles son las tags más importantes.

<section>

<h3>

Esto es un título

</h3>

<p>

Esto es un párrafo. Acá puede ir todo el texto del mundo y otras cosas. Tanto este p como el h3 son descendientes de la section.

</p>

</section>

Estructura principal

Las tags más importante que cualquier sitio debe tener son html, head y body. La primera es la que define los límites del documento, sin esa tag no existe nada. La segunda es para definir información relevante al sitio pero que no va a ser visible para el usuario, eso incluye metadatos y un poco de información extra para que el navegador sepa como interpretar el sitio. Por último, body es donde va el contenido del sitio, básicamente todo.
Cualquier sitio normal sigue el siguiente esquema: 

<html>
    <head>
        Metadatos, estilo, etc...
    </head>
    <body>
        Contenido
    </body>
</html>

Todo lo que están viendo ahora mismo está adentro del body.

¡Pueden ver la estructura de este sitio!

Los navegadores vienen con un "inspector" que puede mostrar la estructura entera de cualquier sitio que visiten. En general se abre con F12 o haciendo click izquierdo en algún lado y dándole a "inspeccionar elemento" (o algo así).
El inspector también puede mostrar muchas cosas más que son muy útiles para el desarrollo web.

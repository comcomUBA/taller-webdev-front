Hypertext Markup Language (HTML)

HTML es un lenguaje para armar documentos.

  • "Hypertext" se refiere a los links que conectan los distintos sitios y documentos.
  • "Markup" se refiere a que se usa una sintaxis particular para marcar cómo se debería estructurar el contenido.
  • Una de las maneras de definir dicha estructura es a través de tags, que son etiquetas que le dicen al navegador qué es (y como tiene que formatearse) cada parte del documento.

Tags

Las tags tienen el siguiente formato:

  • <tag atributos>Contenido</tag>
  • <tag atributos/> para elementos sin contenido.

Donde

  • "tag" es el nombre de la etiqueta, que define qué tipo de elemento es. Algunos ejemplos son p, h1, div.
  • "atributos" son pares clave-valor que le dan información extra al navegador sobre el elemento. Por ejemplo, el atributo "href" de un a le dice al navegador a qué página llevar al usuario cuando hace click.
  • "Contenido" es el texto o los elementos anidados (los "descendientes") dentro de la tag. Por ejemplo,
    <tag a href="http://comcom.dc.uba.ar">Hola mundo</a>
    se ve así: Hola mundo.

<section>

<h3>

Esto es un título

</h3>

<p>

Esto es un párrafo. Acá puede ir todo el texto del mundo y otras cosas. Tanto este p como el h3 son descendientes de la section.

</p>

</section>

Estructura principal

  • html: define los límites del documento, sin esa tag no existe nada.
  • head: acá van los metadatos y otra información que no se ve en el sitio.
  • body: donde va todo el contenido del sitio.

Cualquier sitio normal sigue el siguiente esquema: 

<html>
    <head>
        Metadatos, estilo, etc...
    </head>
    <body>
        Contenido
    </body>
</html>

Todo lo que están viendo ahora mismo está adentro del body.

¡Pueden ver la estructura de este sitio!

Los navegadores vienen con un "inspector" que puede mostrar la estructura entera de cualquier sitio que visiten. En general se abre con F12 o haciendo click derecho en algún lado y dándole a "inspeccionar elemento" (o algo así).
El inspector también puede mostrar muchas cosas más que son muy útiles para el desarrollo web.

Contenidos de head, metadatos

<title>Taller de WebDev</title>

El elemento title se usa para elegir el título de la página. Dicho título es el que se ve en la pestaña correspondiente del navegador.

<link rel="stylesheet" href="diapos.css">

link define relaciones con recursos externos al documento. Se usa principalmente para elegir la(s) hoja(s) de estilos (CSS) pero también otras cosas como el ícono del sitio (suele aparecer al lado del título). En el caso más general usa el atributo href para definir la dirección del recurso y rel para especificar cual es dicha relación.

<style>...</style>

style permite agregar estilo directamente ahí pero no es muy común hacer eso. En este documento no usamos este elemento.

<meta charset="UTF-8">

meta sirve para agregar cualquier otro tipo de información que no se pueda representar con las tags anteriores.

Estructura principal pero menos principal

HTML viene con varios elementos para organizar el sitio, casi todos bastante auto explicativos:
  • header, main y footer para organizar el sitio en esas tres partes.
  • aside para cosas que justamente deberían ir a un costado.
  • article para artículos.
  • div es un contenedor genérico que no representa nada por si mismo. Sin embargo, suele pasar que es el único elemento que se usa para organizar el sitio.

Todos estos elementos tienen formato "block", que, por ahora, significa que ocupan el ancho entero del sitio. (continuará...)

Este documento sigue ese mismo patrón:

  • header, main y footer para las tres partes principales.
  • El resto se divide en sections: cada una de estas cajas grandes es una sección.
  • Que a su vez se dividen en subsections: los textos separados por rayas.
  • Esas rayas son el elemento hr, que se usa para separar cosas.
  • No se usa ningún div (o por lo menos no hasta este punto, todavía estoy escribiendo jiju (al final sí usé divs)).

Texto

Los elementos hN, donde la N va de 1 a 6, son encabezados. La importancia va de menor a mayor, donde h1 es el título principal del documento (y debería haber solo uno) y h6 es un título bastante menor.

h2

h3

h4

h5
h6

Los navegadores les ponen estilos por defecto para reflejar la "importancia", pero todo eso se puede cambiar.

El elemento p representa un párrafo, aunque se puede meter todo el texto que quieran ahí adentro. Todo este texto y el resto de párrafos en estas diapos usan este elemento.

Esos son los principales elementos que contienen texto y ambos tienen formato block.

Pero también hay elementos que modifican el texto que está adentro de los p y h (o en cualquier otro contexto):

  • a es para agregar links
    <a href="...">a es para agregar links</a>
  • strong es para marcar importancia
    <strong>strong es para marcar importancia</strong>
  • em es para énfasis
    <em>em es para énfasis</em>

etc.
Al igual que div, la versión genérica de los modificadores es span. A lo largo de este documento lo estuvimos usando para marcar texto que debería verse como código.

Todos estos elementos tienen formato "inline", lo cual por ahora solo implica que van en el medio del contenido.

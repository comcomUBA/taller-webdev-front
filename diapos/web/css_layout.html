El modelo de caja

Hasta ahora solo cambiamos cómo se ven los elementos en el sitio. Sin embargo, una de las cosas más potentes de CSS es que también podemos cambiar cómo se organizan. Vamos a cambiar el layout del sitio.
En CSS, todos los elementos están en cajas. Estas cajas tienen 4 partes:

  • El contenido: Lo que metemos en los elementos. Texto, imágenes, otros elementos, etc.
  • Padding: Es un relleno alrededor del contenido. Suele verse como parte del elemento.
  • Borde: El espacio entre el padding y el margen. Marca el límite del elemento.
  • Margen: El espacio entre el elemento y otros elementos. En general no se ve como parte del elemento. La interacción entre los márgenes de dos elementos es rara.

En ese orden desde adentro hacia afuera.

Por defecto, el ancho y alto de un elemento se calculan solo en base al contenido, por lo que hay que sumar el padding, borde y margen para conseguir el tamaño total de la caja. La regla box-sizing: border-box permite cambiar esto para que se calcule en base al contenido, padding y borde, sin incluir el margen.

Manipulando la parte de adentro de la caja

También podemos cambiar el tamaño del contenido! O por lo menos intentarlo. Las propiedades width y height hacen exactamente eso. Como dijimos antes, si box-sizing es border-box, los valores de estas propiedades incluyen al padding y el borde.
Acá entramos un poco en terreno tormentoso. Si el tamaño que le damos al contenido no es suficiente, el contenido podría escaparse del contenedor, cosa que se conoce como overflow. Si el tamaño que le damos es demasiado, nos van a quedar agujeros medio raros.

padding: 50px;
border: 5px solid black;

También existen propiedades min-width y max-width (y lo mismo para height) que limitan los valores de las propiedades anteriormente mencionadas. Ahora, ¿por qué existen esas propiedades? ¿Por qué alguien pondría un valor de width mayor al de max-width?

Unidades y un flash de diseño receptivo

Más atrás mencionamos muy al pasar algunas unidades que se usan para los valores de las propiedades. Estas unidades se distinguen en dos categorías:

  • Absolutas: Indican la misma magnitud sin importar en qué contexto aparezcan*. Son cm, mm, Q (¼mm), in, pc, pt y px.
  • Relativas: La magnitud que representan depende del contexto. Ahora entramos más en detalle.

Volviendo a width y max-width, alguien podría definir el ancho de un elemento con una unidad relativa pero después ponerle un límite con una unidad absoulta.
De hecho, en este sitio, tenemos la regla

main {

max-width: 1000px;

margin: auto;

...

}

Como main por defecto tiene display: block, por defecto ocupa el ancho completo de su contenedor, en este caso body. Sin embargo, con max-width: 1000px hacemos que eso solo aplique hasta cierto ancho y después queda fijo para que la cosa se mantenga legible. Por último, margin: auto pone los márgenes laterales que correspondan para que el contenido quede centrado.

Unidades relativas

Las unidades relativas son las siguientes:

  • em se refiere al tamaño de la fuente del elemento al que se le aplica la regla*. 2em es el doble de ese tamaño.
  • rem se refiere al tamaño de la fuente del elemento raíz.
  • vh se refiere a la altura del viewport, el rectángulo en el que se está mostrando el sitio. 1vh es 1% de ese tamaño. La versión para el ancho es vw. Ver las versiones con s, l y d.
  • vmin la más chica entre vh y vw. vmax es la más grande.
  • Los porcentajes se refieren a un porcentaje de la propiedad en el elemento padre. Por ejemplo: width: 50% representa la mitad del ancho que el elemento padre.
  • fr se usa para específicamente para grids.

Hay unas cuántas más mucho más específicas pero no son muy comunes.
